# PrePoMax 응력 시뮬레이션 데이터 요청서

응력 시뮬레이션 담당 팀원용 요청서입니다. 여기 적힌 대로 결과를 뽑아서 넘겨주시면, 그 데이터를 AI 파이프라인이 바로 읽어서 판정 로직에 씁니다.

## 0. 확인해서 알려줘야 할 것 (가장 먼저)

- **좌표계**: `ASSEMBLED_Rocket.STEP`에서 `rocket_middlepart`만 불러왔을 때, 로켓의 길이 방향(위/아래)이 X·Y·Z 중 어느 축인지, 원점(0,0,0)이 어디인지(노즐 쪽인지 반대쪽인지) 알려주세요. → 나중에 "엔진에서 몇 mm 떨어진 위치" 식으로 구역을 나눌 때 필요합니다.
- **단위계**: PrePoMax 프로젝트 생성할 때 단위계를 뭘로 설정했는지(mm-N-s-°C 조합인지, SI(m-N-s)인지) 알려주세요. 아래 물성치 값도 단위계에 맞춰 넣어야 합니다.

## 1. 소재 물성치 (인코넬718 — 아래 값 그대로 입력하면 됨)

이미 공개된 상온(20°C) 기준 대표값입니다. PrePoMax 재료 설정(Material)에 그대로 입력해주세요.

| 물성치 | 값 (SI 단위계용) | 값 (mm-tonne-s 단위계용, PrePoMax 기본값에 가까움) |
|---|---|---|
| 밀도 (density) | 8190 kg/m³ | 8.19e-9 tonne/mm³ |
| 영률 (Young's modulus, E) | 200 GPa = 200000 MPa | 200000 MPa |
| 포아송비 (Poisson's ratio, ν) | 0.29 | 0.29 |
| 항복강도 (Yield strength) | 1035 MPa | 1035 MPa |
| 인장강도 (Ultimate tensile strength) | 1375 MPa | 1375 MPa |
| 열팽창계수 (Thermal expansion) | 13e-6 /°C | 13e-6 /°C |

> 참고: 실제 값은 열처리 방식에 따라 ±10~15% 정도 차이가 납니다. 이번 PoC는 "대표값"으로 진행하고, 나중에 정확도가 중요해지면 출처(Special Metals INCONEL 718 데이터시트 등) 하나를 정해서 통일하면 됩니다.

## 2. 돌려야 할 하중 조건 (시뮬레이션 케이스)

**케이스 1 (필수 — 이것부터 먼저 끝내주세요):**
- **내부 압력 하중**: `rocket_middlepart` 안쪽 면에 균일한 내부 압력 5 MPa를 가한 정적 해석(Static Structural)
- 한쪽 끝(노즐 쪽 또는 기준으로 정한 쪽)은 고정(Fixed) 조건

**케이스 2~4 (여유 되면 추가 — 순서대로):**
- **케이스 2, 축방향 추력 하중**: 반대쪽 끝을 고정하고, 한쪽 끝면에 축 방향 압축력(임의로 1000 N부터 시작, 나중에 조정 가능) 적용
- **케이스 3, 진동 근사 하중**: 옆에서 미는 횡방향(lateral) 정적 힘으로 근사 (실제 진동 해석은 너무 복잡하니 일단 "옆에서 흔들리는 걸 정적 힘으로 흉내낸 것"이라고 이해하면 됩니다)
- **케이스 4, 극저온 열하중**: 전체 온도를 20°C → -196°C로 낮췄을 때 생기는 열응력 (Thermal Structural 해석, 위 열팽창계수 필요)

전부 **선형 정적 해석(Linear Static)** 으로 충분합니다. 비선형/동적 해석은 이번 범위에서 필요 없습니다.

## 3. 결과 내보내기 형식 (제일 중요)

각 케이스마다 **CSV 파일 1개씩**, 다음 컬럼으로 내보내주세요. (`rocket_middlepart`의 **바깥 표면 노드만** — 내부 노드는 필요 없습니다.)

```
node_id, x_mm, y_mm, z_mm, von_mises_mpa
```

- `von_mises_mpa`: Von Mises 등가응력 (PrePoMax 후처리 화면에서 기본으로 보여주는 그 색깔 지도 값)
- PrePoMax에서 CSV로 바로 내보내기가 안 되면, 결과 파일(`.frd`, CalculiX 기본 결과 포맷) 원본을 그대로 주셔도 됩니다 — 저희 쪽에서 변환하겠습니다.

**파일명 규칙:**
```
stress_case1_pressure.csv
stress_case2_thrust.csv   (있으면)
stress_case3_vibration.csv (있으면)
stress_case4_cryo.csv      (있으면)
```

## 4. 같이 보내줄 메타데이터 (파일 하나에 메모 형식으로)

- 사용한 단위계 (SI or mm-tonne-s)
- 메쉬 요소 크기/개수 (대략)
- 각 케이스의 하중 크기·방향·고정 위치 (위 표에서 실제로 적용한 값)
- 좌표계 원점/축 정의 (0번 항목에서 확인한 내용)
