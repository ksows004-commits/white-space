[화면] 발표자료 슬라이드 또는 텍스트 오버레이 (코드 화면 아님)

나레이션 예시:
"발사체 부품 검수는 전통적으로 Fail/True, 즉 합격·불합격 이분법입니다.
기준에 못 미치면 부품은 그냥 폐기됩니다. 하지만 부품마다 완성도가 다르고,
저응력 부위에는 결함이 있어도 충분히 쓸 수 있는 경우가 많습니다. 저희는
'버릴지 말지'가 아니라 '어디에 쓸지'를 판단하는 AI 에이전트를 만들었습니다."

"발사체 동체외벽, 인코넬718 소재를 대상으로, 실제 FEA 시뮬레이션 결과(4개
하중 조건, 노드 32만여 개)를 기반으로 합니다. 모든 판정은 실측 데이터와
공개된 공학 공식만 사용하고, 숫자를 지어내지 않습니다."

0:35 - 1:10  핵심 플로우 — 업로드부터 판정까지
------------------------------------------------------------------
[화면 녹화 시작] 브라우저 http://localhost:3000

1. (0:35) 회차 목록 화면 — 빈 상태 또는 기존 회차 보여주기

   선택 (Pass 21 / Conditional Pass 9, 30개 부품 — 가장 균형 잡힌 파일)
3. (0:45~0:55) 업로드 처리 중 화면 → 자동으로 회차 상세 페이지 이동
4. (0:55~1:10) 부품 목록 표(판정/재배치 가능 구역 열) 보여주며 설명

나레이션 예시:
"CSV 파일을 업로드하면, GPU 서버에서 실제 응력 데이터와 결함 위치를 대조해
부품마다 판정합니다. 30개 부품 중 21개는 결함이 없어 Pass, 9개는 결함이
있지만 재배치하면 쓸 수 있는 Conditional Pass입니다."

1:10 - 1:40  핵심 가치 증명 — 재배치 가능 구역 지도
------------------------------------------------------------------
[화면] Conditional Pass 부품 하나 클릭 → 상세 화면

   쓸 수 있습니다" 설명

나레이션 예시:
"이 부품은 결함이 있는 그 자리에서는 못 쓰지만, 116개 구역 중 104개

통해 실제로 쓸 수 있게 되는 겁니다 — 이게 저희 프로젝트의 핵심입니다."

자유롭게 물어볼 수 있습니다. 작업지시서까지 자동으로 만들어져서, 바로
